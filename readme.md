Публикации содержат прямую ссылку на товар внутри сообщения с включённым предпросмотром Telegram; ссылка на обсуждение не выводится.
Бот извлекает ссылки из полного RSS-содержимого, раскрывает известные переходы агрегаторов
и при необходимости проверяет кнопку покупки на странице предложения. Адрес товара не
угадывается по названию. Если получить ссылку не удалось (например, HTTP 403), предложение
остаётся в очереди до следующего запуска, пока не устареет. Доступность товара и его цена
в магазине отдельно не подтверждаются.

Поддерживаемые магазины перечислены в `store_links.py` (`MERCHANTS`). Amazon принимается
только с идентификатором ASIN, Newegg — с путём товара `/p/` или параметром `Item`.

### Прямые магазины и производители

Кроме агрегаторов бот самостоятельно читает публичные каталоги Amazon, Newegg,
Corsair (RAM, БП, охлаждение, мыши, клавиатуры, гарнитуры), MSI, Samsung, Crucial,
ASUS и Google Store. Источники с `type="store"` включены по умолчанию; их ID
перечислены в `sources.py`. Отключение — через `DISABLE_SOURCES`, как и для RSS.

Цены берутся из карточек товаров, JSON-LD и данных каталога магазина. Варианты с
неоднозначной ценой, другой валютой, отсутствием на складе или предзаказом
пропускаются. Для Corsair дополнительно проверяются наличие и цены конкретного SKU
в `__NEXT_DATA__`. Обычная цена магазина обозначается как MSRP, а не выдаётся за
подтверждённую историческую цену. Если магазин не сообщает исходную цену, бот
накапливает собственную историю этого товара в этом магазине и ждёт подтверждения
скидки по прежним правилам. Дата обхода каталога не является датой публикации акции.

Каталоги опрашиваются раз в 15 минут, недоступные магазины — раз в 30 минут.
HTTP 403/503, CAPTCHA и отсутствие читаемых цен видны как ошибки источника; обход
блокировок не выполняется. При проверке из текущей среды Amazon, Newegg и MSI
блокировали запросы, а Google Store не отдавал однозначные цены Pixel в HTML.
Наличие адаптера не гарантирует доступность магазина с IP GitHub Actions.

Комплектующие, периферия и Google Pixel публикуются перед ноутбуками/готовыми ПК.
Добавлены категория микрофонов, категория Pixel и поисковые RSS-запросы по Pixel,
мышам, клавиатурам, гарнитурам и микрофонам. Цены Pixel с trade-in, активацией тарифа
или ежемесячными платежами не считаются обычной ценой покупки.

Новых Python-зависимостей нет: непрерывный workflow может подхватить изменения через
имеющийся `sync_code`. Новые значения Variables/Secrets запущенный job автоматически
не перечитывает, но для включённых по умолчанию прямых источников это не требуется.

### Синхронизация непрерывного запуска

`workflow_git.py` сохраняет `data/` отдельным коммитом поверх свежей удалённой ветки
через временный Git index. Rebase для сохранения состояния не используется.
При обновлении кода локальные данные сначала копируются за пределы checkout,
незавершённая Git-операция отменяется, затем данные восстанавливаются поверх
обновлённого checkout. Этот helper разрешено запускать только в GitHub Actions.

Если состояние не удалось отправить за три попытки или JSON повреждён, цикл
останавливается; `data/` сохраняется как Actions artifact на 7 дней. Следующий
запуск по цепочке выполняется только после успешного завершения предыдущего.
Изменения самого workflow требуют нового запуска: текущий shell-скрипт цикла
не перечитывается при `sync_code`.

### Ссылки и фото в публикациях

Предложения отправляются текстом через `sendMessage`, без кнопки «В магазин» и без отдельного `sendPhoto`. Прямая ссылка «Открыть товар в магазине» находится рядом с ценой. В `link_preview_options` явно указан URL предложения, включён предпросмотр и запрошено крупное изображение под текстом. Ссылки на сравнение цен и канал не меняют выбранный предпросмотр. Наличие фотографии зависит от доступности страницы и метаданных магазина для Telegram. Уже отправленные сообщения не изменяются.

В поиск по умолчанию включены `drum machine`, `sampler`, `synthesizer`, `Roland AIRA`. Музыкальное оборудование распознаётся как `music_gear` раньше компьютерных клавиатур; стандартный порог скидки — 20% и $30, переопределение: `RULES_JSON`. Поисковые источники активны без изменения `ENABLE_SOURCES`, кроме явно отключённых через `DISABLE_SOURCES`.

### Сравнение цен между магазинами

Если собственной истории ещё нет и обычные правила не подтверждают скидку, бот пробует сравнить предложение с **двумя другими независимыми магазинами**. За базу берётся самая низкая из подтверждённых цен, а к цене предложения прибавляется известная доставка. Пороги категории из `RULES_JSON` сохраняются. Например, $500 против $750 и $800 может пройти проверку уже при первом наблюдении.

Сопоставление строгое: проверенный GTIN или бренд + MPN производителя. Для Google Pixel допускается полное совпадение поколения, Pro/XL/Fold, памяти, цвета и явно указанного unlocked; противоречащие GTIN/MPN исключаются. Автоматическое сравнение применяется к новым товарам с обычной ценой, без trade-in, тарифа, купона, членства и подобных условий. Наличие, USD и продавец должны подтверждаться страницей магазина. Для маркетплейсов принимаются только явно указанные Amazon, Newegg и другие поддержанные собственные продавцы площадок. Неизвестная доставка текущего предложения блокирует этот способ подтверждения. Налоги по адресу покупателя не рассчитываются.

Цены из RSS-заголовков, MSRP и поисковых сниппетов не являются рыночными доказательствами. Бот использует структурированные данные прямых каталогов и перепроверяет точные товарные ссылки, найденные в подключённых источниках. Известные ссылки хранятся до 30 дней (до 2000), подтверждённые цены — 15 минут (до 1000). На цикл допускается до 8 дополнительных запросов, новые запросы перестают начинаться после 45 секунд; неудачные проверки повторяются не чаще раза в 10 минут. Сплошного поиска по всему интернету нет: без обнаруженных ссылок на конкурентов сравнение не сработает. Amazon/Newegg с блокировкой HTTP 403/503 остаются недоступными для подтверждения; обход защиты и платный сервис не подключены.

В публикации указываются минимальная цена других магазинов, экономия и ссылки на подтверждения. Ссылка внутри сообщения ведёт на проверенное предложение. Подходящие, но неподтверждённые предложения сохраняются для повторной автоматической оценки, пока не истечёт `MAX_AGE_H` (до 500 записей). Раздел отчёта «Не опубликованы — причины автоматической проверки» объясняет недостающие данные; ручного одобрения он не требует.

### Защита непрерывного цикла

Перед заменой checkout `workflow_git.py sync` компилирует все Python-файлы удалённого коммита. При синтаксической ошибке обновление отклоняется, локальное состояние сохраняется, run завершается с ошибкой. Перед каждым проходом также проверяется синтаксис. Один проход ограничен 10 минутами (затем TERM и через 30 секунд KILL); после трёх подряд неуспешных проходов цикл завершается и освобождает очередь. Успешный проход сбрасывает счётчик. Safety net сохраняет `data/`, а при сбое создаётся artifact.

Один ожидающий запуск при работающем цикле допустим: `concurrency` запрещает параллельных издателей, чтобы не дублировать сообщения. Изменения оболочки workflow вступают в силу в новом запуске.
