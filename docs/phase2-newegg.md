# Newegg: агрегаторы при недоступной карточке

В 1321 pending нет первичных Newegg-предложений. Четыре статьи Tom’s Hardware содержат семь Newegg-ссылок, все уже корректно раскрывались; 52 из 143 market-search записей упоминают Newegg только как сравнение. Resolver не переписывался, добавлены регрессии /p, Item, u2 и отказа search/cart/lookalike.

Сравнение использует точную идентичность и >=2 свежих независимых магазинов. Цена Newegg из фида не становится магазинной котировкой. Неизвестная доставка не позволяет заявить экономию с доставкой. Явный ответ карточки с другой ценой/версией/условиями запрещает fallback.

Для curated/community при недоступной карточке сохраняются проверка срока, категории, условий и голосов; экстремальная скидка сама по себе не запрещает публикацию. Текст сообщает: «Цена из агрегатора, не проверена на странице Newegg». Unvetted всегда требует сравнения. Поиск sd-q-newegg добавлен как unvetted, проба runner: 200/25 записей.

Внешний сборщик выключен/не реализован: отдельного сервера нет, домашний компьютер возможен только при отдельном решении о запуске. Владелец выбрал только бесплатные источники. Бот продолжает работать независимо от этого варианта.
