Очередь: каждый входящий кандидат сначала оценивается; в конце прохода сохраняется до 500 ожидающих. Приоритет: неопределённая доставка, экстремальное снижение, комплектующие/периферия/Pixel/музыка, ноутбуки/готовые ПК, нераспознанные категории. Внутри приоритета — чередование source+brand и свежие первыми. Вытеснение не создаёт processed/отказ и не меняет floors; позиция может поступить повторно. Sending/delivery_unknown не удаляются по возрасту/лимиту (мягкий лимит может быть превышен). Существующая политика повторной попытки неопределённой доставки не изменена.

Рыночный поиск уже чередует производителей по brand_searched; сохранено. Новый тест: 600 Corsair не вытесняют MSI/Samsung. Новых полей состояния нет. RULES_VERSION=5 инвалидирует прежние оценки.
